# CampusPrint -- Wireframes

## 1. Purpose

This document provides low-fidelity wireframes and layout guidance for
every major screen in CampusPrint. It focuses on structure, hierarchy,
and navigation rather than visual styling.

# 18. Accessibility

-   Keyboard navigation
-   Visible focus states
-   Screen-reader labels
-   Minimum touch targets
-   High contrast support

------------------------------------------------------------------------

# 19. Acceptance Criteria

Wireframes are complete when every major user journey has a
corresponding layout with clearly defined navigation and content
hierarchy.
